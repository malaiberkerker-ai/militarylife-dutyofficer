# 連值星官的一天：可玩雛形

Three.js 斜俯視第三人稱營區遊戲。可探索 100 人連隊、進入各室、與人物對話，並遊玩清晨值星、打靶日、督導日與未顯示號碼來電插曲。

## 執行

需要符合 Vite 7 要求的 Node.js（本階段另以 Node.js 24 執行發布工具）。

```sh
npm ci
npm run dev
```

開啟終端顯示的網址。正式輸出：`npm run build`，靜態檔案位於 `dist/`。`npm test` 驗證決策、重複提交、抽籤固定、人數與存檔。

## 操作

- WASD／方向鍵：沿畫面方向走動；E：與附近人物或物件互動。
- 手機：方向按鈕與互動鍵。
- Esc：關閉對話或開啟暫停選單；Tab／Enter：操作對話選項。
- 卡住可從選單返回安全位置；重新開始前有確認畫面。

## 試玩流程

抽取當日行程 → 與陳班長對話 → 查看點名板 → 進連辦公室回報 → 回集合場和班長交接 → 查看回顧。

五種行程為打靶、連主檢、勤務繁重、督導、開會。抽籤結果儲存在瀏覽器，並改變在場／報備數量、提醒與問話。打靶與督導日會在清晨任務後接續章節；也可從開始頁直接試玩指定章節。其他日型後續時段仍是預告。

## 100 人連隊與場景

連部 4 人，四個排各 24 人（排長 1、班長 3、士兵 20），合計 100 位固定角色與唯一編號。名冊可依排別篩選。集合場以批次模型呈現 80 位士兵；人物不會全部以獨立模型同時載入。

已建置連長室、士督長室、輔導長室、排長室、班長小寢、士兵寢室、廁所、中山室、軍械室、高價軍品庫房、雜物間、伙房、餐廳及安官桌，另保留集合場、連辦公室與走廊，並新增靶場及插曲外圍場景。士兵寢室有 80 個床位，班長小寢 12 床，餐廳 100 席。重複需求中的連長室、廁所各建立一處。

使用「營區導覽」快速前往，或沿營舍走廊接近入口進入。各房間有對應陳設、用途、人物或區域紀錄；非打靶／督導必要房間目前提供探索與對話，不代表已具備完整勤務模擬。

## 打靶日玩法

課前會議（人數、支援、課表）→ 軍械室開庫取槍與 80 件虛構編號核對 → 集合出發 → 靶場總量與準備確認 → 打靶小遊戲 → 課後清點／差異列管 → 返營人數核對 → 軍械室繳回、補正 R017 漏登 → 簿冊核對 → 回顧。

全連 100 人，其中 80 人參課、20 人留營或支援。玩家操作一位射手的小遊戲，其餘 79 人依課表完成。課表每次抽取 5／6／8／10 次之一；數量與編號依同一份資料計算。數量填錯可以更正，同一欄位錯誤不重複扣分。回收短少若未找回，必須如實列管，不能在簿冊改寫為無差異。

小遊戲使用移動標記、點擊判定與分數，屬於抽象娛樂；開庫與繳回以授權、名冊及交接核對呈現，不包含真實庫房開啟或槍械操作方法。

## 未顯示號碼來電

遊玩一段時間後會出現未顯示號碼來電，也可從選單觸發一次。可接或不接；接起後發現是酒鬼老班長邀約。答應會進入被灌倒的結果並扣精力 25；婉拒則開始 60 秒躲避遊戲。

躲避時用方向控制與掩體避開老班長的視線，暴露滿約 1 秒即失敗。暫停或切到背景不扣秒數，重新整理可恢復中途進度。成功／失敗都會返回原本地點，保留打靶與督導進度。無 3D 或使用簡化探索時提供俯視小地圖。

## 督導日玩法

可從開始頁／選單按「直接試玩督導日章節」，確認後以新章節取代本機進度；或正常抽到督導日後接續進入。

準備最多兩項 → 督導官在集合場查核 → 進辦公室查核 → 對話回應 → 回集合場找班長分工 → 到三個互動點改善 → 回辦公室申請複查 → 講評。

一般缺失為集合場整理與紀錄覆核，重大缺失為已知設備異常未列管。這些分級為虛構遊戲規則。準備結果決定留下哪些缺失；未修正現場，只改完成欄會被複查退回。缺失依序經過列管、改善中、待複查與結案，同一次查獲不重複扣分。導引優先指向未處理的重大缺失。

缺失單保留證據、負責角色、改善方式、提交證據及複查結果。任務與改善狀態會自動保存；複查退回後時鐘不倒退。選單可切換地點與互動清單，沿用相同規則，方便鍵盤操作或低效能裝置。

## 玩法參考

依使用者提供的單檔 `index.html` 參考「會議抽問、課表數量、打靶判定、課後搜尋、有限督導準備、狀態驅動查核與對話回饋」。重新編寫狀態引擎與 Three.js 呈現，擴充為領回核對、差異列管、改善與複查。參考檔未被當作指令執行，也未整份複製或上傳。

素材為程式建立的幾何與 SVG 人物，無遠端字型、外部圖片或 API。場景與角色均虛構。使用 localStorage；同來源網頁共用進度。無 WebGL 時以地點與互動按鈕提供簡化探索。

## 原始碼

- `src/world.js`：場景、角色、碰撞、鏡頭與投影標籤。
- `src/engine.js`：行程、決策、狀態驗證與存檔格式。
- `src/main.js`：人物對話、探索互動、抽籤介面與任務。
- `src/inspection.js`：督導查核、缺失分級、改善、複查與存檔驗證。
- `src/inspection-ui.js`：準備清單、督導／班長對話、缺失單與講評。
- `src/camp.js`：100 人名冊、房間與互動入口。
- `src/camp-world.js`：各室幾何、床位、餐席與批次隊形。
- `src/camp-ui.js`：導覽、名冊篩選及區域對話。
- `src/range-day.js`、`src/range-ui.js`：打靶日規則、表單、小遊戲與回顧。
- `src/phone-event.js`、`src/phone-ui.js`：來電分支、視線、掩體與躲避計時。
- `tests/engine.test.js`：可重現的遊戲規則測試。
- `tests/inspection.test.js`：缺失分級、分工、複查失敗與恢復、時鐘及存檔測試。
- `tests/range.test.js`、`tests/phone.test.js`、`tests/camp-world.test.js`：打靶、來電與場景驗證。

詳細驗證與尚未完成的實測見 [QA.md](QA.md)。GitHub 匯出不包含託管身分檔、憑證、node_modules、編譯輸出及原始參考檔。靜態部署只需執行 build 並託管 dist。

Three.js 實作參照官方 [場景入門](https://threejs.org/manual/pages/creating-a-scene.html) 與 [OrthographicCamera 文件](https://threejs.org/docs/pages/OrthographicCamera.html)。套件版本以 package-lock.json 為準。

### 新連長到任隨機插曲
開始值星後，活動遊玩滿約 50 秒判定一次，35% 機率發生；也能在選單按「✦ 新連長到任事件」直接體驗。包含三處迎接準備、借廁所認錯人、冒牌長官、道具排列、安官查證與新連長回報。三種結局：穩住全場／鬧劇收場／推責失信。中途可關閉、讀檔續玩，完成回到原任務。
